# Sound Playground — downloads

This repository exists so there is somewhere public to download Sound Playground
from. **There is no source code here**, and there never will be: it holds
releases and nothing else.

## Get it

Everything is on the [latest release](../../releases/latest).

| Your computer | The file |
|---|---|
| Windows | `sound-playground-x86_64-pc-windows-msvc.msi` |
| Windows on ARM (Surface, Snapdragon) | `sound-playground-aarch64-pc-windows-msvc.msi` |
| Any Mac | `sound-playground-macos-universal.dmg` |
| Linux | `sound-playground-x86_64-unknown-linux-gnu.tar.xz` |
| Raspberry Pi 5, or other ARM Linux | `sound-playground-aarch64-unknown-linux-gnu.tar.xz` |

The Windows file is an installer — Sound Playground appears in the Start menu
and in *Add or remove programs*. The Mac file is a disk image: open it and drag
the app into Applications. The Mac file works on every Mac; you do not need to
know which chip is in yours.

`sha256.sum` on the release lists the checksum of every file, if you want to
check a download arrived intact.

## What it is

A music playground for children that runs entirely on the computer it is
installed on. One file to open, nothing else to install first, and no account.
Nothing a child makes leaves their machine.
